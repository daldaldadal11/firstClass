# Orion 리뉴얼 Design System

> 기준: `orion/index.html`, `orion/css/main.css`, 공통 `css/default.css`의 현재 구현. 메인페이지를 기준 레퍼런스로 삼으며, 이 문서는 이후 서브페이지의 디자인·UI 구현 규칙이다. 기존 메인페이지를 수정하거나 이 문서만을 근거로 메인 디자인을 변경하지 않는다.
>
> **수치 원칙:** 아래 값은 현재 코드에서 확인한 값이다. 명시되지 않은 디자인 토큰이나 브레이크포인트를 새로 표준처럼 만들지 않는다. 코드에 직접 지정된 값과 CSS 변수 값을 구분한다.

## 1. Project Overview

오리온 기업 브랜드 및 제품 브랜드(오리온·닥터유·마켓오네이처·바이오)를 소개하고, 윤리경영·뉴스룸·투자정보를 전달하는 기업 웹사이트 리뉴얼이다.

- 메인 히어로는 브랜드별 이미지와 카피를 크게 노출하고 Swiper로 전환한다.
- 기업 정보 섹션은 흰 배경과 넓은 콘텐츠 폭을 사용해 읽기 쉽게 구성한다.
- 투자정보는 짙은 차콜 배경과 대비되는 카드로 분리한다.
- 서브페이지에서도 메인과 같은 헤더·내비게이션·타이포·컬러·콘텐츠 폭·카드/버튼 언어를 유지한다.

## 2. Brand Identity

- **핵심 인상:** 기업다운 신뢰감, 명료함, 절제된 현대성. 넓은 여백과 큰 제목, 단정한 정렬을 사용한다.
- **브랜드 컬러:** 오리온 레드가 핵심 포인트이며, 브랜드별 히어로 카피에는 오리온 레드와 마켓오네이처 올리브 컬러를 사용한다.
- **이미지 중심:** 히어로와 카드에서 사진을 넓게 사용하고 `object-fit: cover`로 영역을 채운다. 텍스트는 이미지 위에서 명확히 읽히도록 대비를 확보한다.
- **형태:** pill 형태의 CTA/탭, 모서리가 살짝 둥근 카드, 얇은 경계선, 원형 화살표 버튼 등 반복되는 형태를 유지한다.

## 3. Design Principles

1. **메인페이지를 기준으로 확장:** 새 서브페이지는 기존 메인에서 확인되는 컴포넌트와 규칙을 재사용한다. 임의로 다른 디자인 시스템을 도입하지 않는다.
2. **명확한 위계:** 제목은 굵고 크게, 설명은 중간/보조 색과 넉넉한 행간으로 구분한다.
3. **정렬과 폭 통일:** 주요 콘텐츠는 중앙 정렬 컨테이너 안에 배치한다. 섹션마다 임의의 폭을 만들기보다 기존 `1380px`, `1520px`, `1720px`, `1920px` 기준을 목적에 맞게 사용한다.
4. **색상 절제:** 흰색/차콜/회색 중립색을 바탕으로 레드 포인트를 사용한다. 브랜드 컬러를 장식 목적으로 과도하게 반복하지 않는다.
5. **이미지와 텍스트의 균형:** 이미지 위 텍스트에는 오버레이/대비를 적용하고, 카드 제목과 정보는 정해진 내부 여백에서 시작한다.
6. **상태를 분명히:** hover·active·focus는 색, 배경, 이동 또는 밑줄 등 기존 방식으로 구분하고 키보드 포커스를 제거하지 않는다.

**적용:** 새 페이지에서는 우선 위 CSS 변수를 사용한다. 기존 페이지의 직접 지정 색은 해당 컴포넌트 맥락에서 재사용할 수 있다. 문서에 없는 색을 임의로 추가하지 말고 기존 토큰/색과 목적을 맞춘다.

## 6. Layout & Spacing

### 컨테이너 기준

| 용도 | 기준 |
|---|---|
| 사이트 헤더 내부 | 최대 1920px, 높이 80px, 좌우 padding 24px |
| 히어로 카피 | 최대 1520px, 좌우 최소 여백 계산식 `calc(100% - 80px)` |
| 히어로 하단 컨트롤 | 최대 1720px, 좌우 `calc(100% - 80px)` |
| 윤리/뉴스/투자 콘텐츠 | 최대 1380px, 중앙 정렬 |
| 푸터 콘텐츠 | 최대 1720px, 중앙 정렬 |

컨테이너는 `margin: 0 auto`로 가운데 정렬한다. 전체 폭은 `width: min(100%, 기준폭)` 또는 `max-width` 방식으로 제한한다.

### Grid / Flex

- **Header:** flex로 로고·GNB·언어/메뉴 도구를 가로 정렬. 데스크톱 GNB 간격 99px, 도구 간격 48px, GNB와 도구 그룹 사이 302.5px(1600px 이하에서는 반응형 간격으로 변경).
- **윤리 카드:** 데스크톱 4열 Grid, 열 간격 22px, 2행 각 320px. 네 번째 카드가 2행을 세로로 차지한다. 700px 이하에서는 2열·220px 행·12px gap으로 재배치.
- **뉴스 카드:** 데스크톱 3열 Grid, gap 20px. 모바일 700px 이하 1열, gap 22px.
- **투자정보:** 왼쪽 소개/오른쪽 카드의 2열 Grid(`.88fr / 1.12fr`), gap 70px. 900px 이하 1열. 카드 목록은 세로 Grid gap 27px.
- **푸터:** 상단은 Flex 양 끝 정렬, 본문은 Grid(정보 영역 + 오른쪽 링크 영역).
- **간격:** 기존 CSS에 지정된 섹션 padding, 카드 padding, gap을 우선한다. 새 섹션은 인접한 기존 섹션의 리듬을 참고하고 근거 없는 고정 수치를 만들지 않는다.

## 7. Components

### Header / GNB

- `.site-header`: 히어로 위에 absolute 배치, 80px 높이, z-index 20. 헤더 자체가 히어로 위에 겹치므로 별도 상단 공간을 추가하지 않는다.
- `.header-inner`: 최대 1920px, 80px 높이, 중앙 정렬.
- `.header-logo img`: 120px 너비(최대 높이 48px).
- `.header-nav`: flex, gap 99px. 링크 18px/500.
- `.header-tools`: 언어와 메뉴 아이콘 사이 gap 48px. 메뉴 아이콘 24×24.
- 오리온/바이오 슬라이드에서는 inverse(흰색) 헤더, 닥터유/마켓오네이처에서는 primary(어두운 텍스트/아이콘) 헤더를 사용한다.
- 메뉴 오버레이는 헤더 아래 80px에서 펼쳐지고, 흰색 82% + blur 18px 배경을 사용한다. 메뉴 컬럼은 너비 150px, 상단 레드 2px 선과 활성 시 아주 옅은 회색 배경을 가진다.
- GNB hover 시 클릭 없이 메뉴가 열리며, 트리거와 서브메뉴 영역은 하나의 hover surface로 취급한다. 영역을 벗어나면 닫힌다.

### Footer

- 배경 `#222`, 텍스트 기본 `#777`, 주요 링크 `#f4f4f4`.
- 내부 최대 폭 1720px, 상단 영역 최소 높이 94px, 아래쪽 padding 42px.
- 상단 로고 122px, 주요 링크 gap 72px.
- 회사 정보는 주소·사업자/대표/전화/고객센터를 DL 형태로 정리하고, 저작권 문구를 별도 배치한다.
- 우측에는 법적 링크, 패밀리 사이트 토글, 소셜 아이콘을 정렬한다.
- 패밀리 사이트는 버튼 클릭으로 열고, 외부 영역 클릭 시 닫는다. `aria-expanded` 상태도 함께 갱신한다.

### Buttons / CTA

- **히어로 CTA `.hero-more`:** 179×60px, 흰 테두리 1px, pill radius 50px, 아이콘과 텍스트 gap 20px. hover 시 흰 배경/기본 텍스트 색으로 반전하고 아이콘을 어둡게 한다.
- **투자 CTA `.investment-more`:** inline-flex, 최소 높이 54px, 흰 테두리, pill, 텍스트와 화살표 gap 18px.
- **뉴스 탭 `.newsroom-tab`:** 최소 높이 40px, 좌우 padding 19px, 1px 테두리, pill. 기본 흰색/회색 글자, active는 `#c60020` 배경과 흰 글자.
- **뉴스 화살표 `.newsroom-arrow`:** 54×54px 투명 배경, 이미지 아이콘. 비활성은 disabled 속성 및 기본 커서.
- **히어로 화살표:** 56×56px 원형, 흰색 반투명 테두리. hover에 흰색 14% 배경.
- **패밀리 사이트:** 버튼과 펼침 메뉴로 구성하며 열림 상태를 시각/ARIA로 동기화.

### Cards / Links

- **윤리 카드:** 이미지 전체를 링크 영역으로 사용, radius 5px, overflow hidden. 이미지 hover scale 1.04( .45s ). 텍스트는 왼쪽 50px·위 50px, 28px bold. 화살표는 왼쪽 50px·아래 50px, 36×36px.
- **뉴스 카드:** 이미지 비율 1.085:1, radius 6px. hover 이미지 scale 1.035(.4s). 제목 2줄 clamp, 날짜는 보조색.
- **투자 카드:** 최소 높이 200px, padding 48px 46px, radius 10px, 밝은 회색 표면/차콜 텍스트. hover 시 translateY(-3px), .25s. 주가 카드는 레드 배경/흰 텍스트로 강조.
- **링크:** 기본적으로 텍스트 장식 없이 사용하며, 카드 링크는 전체 카드 클릭 영역을 확보한다. 서브페이지의 breadcrumb·본문 링크도 본문과 구별되는 hover/focus 상태를 제공한다.

## 8. Interaction

- **Transition:** 일반 색상 변화는 약 .2s, 카드/이미지 움직임은 .25~.45s, 히어로 카피는 .6~.75s, 메뉴 전개는 .36~.52s를 사용한다. 새 인터랙션은 기존 움직임의 속도감과 easing을 참고한다.
- **Hero:** Swiper loop, 전환 speed 1600ms, autoplay delay 5000ms, progress animation 6.6s. 마우스 진입으로 autoplay가 멈추지 않는다. 슬라이드 카피는 opacity와 translateY로 순차 등장한다.
- **GNB:** mouseenter로 메뉴를 열고 active 항목을 표시한다. 메뉴/컬럼 hover 중에는 열린 상태를 유지하고 overlay mouseleave에서 닫는다. 활성 메뉴 텍스트와 상단선은 레드.
- **카드:** 이미지 확대 또는 카드의 미세한 위쪽 이동. 콘텐츠 자체의 크기/레이아웃은 hover 때문에 흔들리지 않게 한다.
- **버튼:** hover 시 배경/텍스트/아이콘 대비를 바꾸며, active 상태는 탭의 레드 채움처럼 명확하게 표시한다.
- **Focus:** 공통 reset의 `:focus-visible`은 `2px solid currentColor`, `outline-offset: 2px`. 키보드 접근성을 위해 focus outline을 제거하거나 무시하지 않는다.
- **Reduced motion:** `prefers-reduced-motion: reduce`에서 공통 reset이 animation/transition을 최소화한다. 새 컴포넌트도 이 대응을 유지한다.

## 9. Responsive Rules

현재 코드에서 확인되는 기준점만 사용한다.

- **1600px 이하:** 헤더 좌우 padding 40px, GNB gap은 `clamp(24px, 4vw, 64px)`, header 그룹 간격 24px, 도구 gap 32px.
- **1024px 이하:** 헤더 72px, 로고 104px, 데스크톱 GNB 숨김. 히어로 PC 이미지 숨기고 모바일 이미지 표시. 히어로 높이 96dvh(최소 620px), 컨트롤과 카피 크기 축소.
- **900px 이하:** 투자정보 Grid를 1열로 변경.
- **700px 이하:** 윤리/뉴스/투자/푸터의 모바일 padding·폰트·Grid 적용. 윤리 2열, 뉴스 1열, 투자 카드/텍스트 축소.
- **560px 이하:** 히어로 최소 높이 560px, 카피/CTA 축소, 하단 컨트롤 wrap 및 진행바를 별도 줄로 배치.
- 모바일 메뉴 오버레이는 1024px 이하에서 숨긴다.

새 서브페이지도 위 breakpoint에서 우선 조정한다. 기존에 없는 임의의 breakpoint를 추가하기보다 현재 구간에 맞춰 대응한다. 모바일에서 콘텐츠가 넘치면 열 수와 내부 여백을 줄이고, 텍스트/버튼은 읽고 누를 수 있는 크기를 유지한다.

## 10. Do & Don't

### Do

- 메인에서 쓰는 Pretendard Variable, 컬러 변수, 콘텐츠 폭, 헤더/푸터 구조를 재사용한다.
- 제목·본문·보조정보의 크기와 색 차이를 유지한다.
- 중앙 컨테이너와 일관된 좌우 정렬을 사용한다.
- 이미지에는 적절한 `object-fit`, 카드에는 기존 radius/hover를 적용한다.
- 모든 상호작용 요소에 hover와 keyboard focus를 제공한다.
- 활성 메뉴/탭은 색과 상태로 명확히 표현하고 ARIA 상태를 동기화한다.
- 새 페이지 링크는 리뉴얼 프로젝트 내부 경로 또는 현재 페이지의 기능으로 연결한다.

### Don't

- 기존 메인페이지의 디자인·레이아웃·Swiper·애니메이션·색을 이 문서 작업을 이유로 변경하지 않는다.
- CSS에 없는 색, font, spacing, radius, breakpoint 값을 브랜드 표준인 것처럼 임의로 선언하지 않는다.
- 기존 브랜드 사이트(오리온 공식 사이트 등)로 링크를 연결하지 않는다. 링크는 프로젝트 내부 서브페이지/앵커/구현된 기능으로 연결하고, 미구현 링크는 임시 외부 URL 대신 명확한 placeholder 처리 또는 비활성 상태로 둔다.
- 버튼/카드의 hover만으로 중요한 정보를 전달하지 않는다.
- focus outline을 전역에서 제거하지 않는다.
- 모바일에서 데스크톱 고정 폭을 그대로 유지해 가로 스크롤을 만들지 않는다.
- 임의의 장식, 과도한 그림자/그라데이션, 새로운 브랜드 색을 추가하지 않는다.
